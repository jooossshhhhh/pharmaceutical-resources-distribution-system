## Conventions

- **Filename:** `Issue-###-<short-title>.md` — numbered sequentially, title based on the issue.
- **Time tracking:** every issue file carries `Date Reported` (when the issue first appeared) and `Date Resolved` (when it was fixed) in its metadata block.
- **Lifecycle:** `Open` → `In Progress` → `Resolved`. Update the `Status` and `Date Resolved` fields once fixed.
- Add new issues to this index when created and update the row when the status or dates change.
